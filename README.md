# 🔎 OSINT Nickname Search

Современная десктопная OSINT-утилита для поиска публичной информации по никнейму.

**Автор:** **flelelox**

---

## 📖 Описание

**OSINT Nickname Search** — это инструмент, предназначенный для автоматизированного поиска открытой информации о пользователях по их никнейму (username).

Программа позволяет быстро проверить наличие аккаунта на различных сервисах, собрать результаты в одном месте и экспортировать их в удобные форматы.

Утилита построена на модульной архитектуре, благодаря которой новые платформы можно добавлять в виде отдельных плагинов без изменения основного кода.

Поиск выполняется исключительно по открытым (публичным) данным.

---

---

## 📦 Архитектура проекта

Проект разделён на независимые модули:

- **UI** — графический интерфейс
- **Search Manager** — управление поиском
- **Plugin Manager** — загрузка плагинов
- **Plugins** — отдельные сервисы поиска
- **Export** — экспорт результатов
- **Core** — HTTP-клиент, утилиты и общие компоненты

Такой подход позволяет легко добавлять новые функции и поддерживать проект.

---

## 🌐 Поддерживаемые сервисы

В зависимости от установленных плагинов приложение может выполнять поиск на различных публичных площадках, например:

- GitHub
- GitLab
- Reddit
- Mastodon
- Dev.to
- Hacker News

Список сервисов можно расширять, создавая собственные плагины.

---

## 📄 Экспорт результатов

После завершения поиска результаты можно сохранить в одном из форматов:

- HTML
- PDF
- JSON
- CSV

Это удобно для подготовки отчётов, архивирования результатов или последующего анализа.
